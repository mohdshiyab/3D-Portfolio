## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/mohdshiyab/your-portfolio-repo.git
```

Go to the project folder

```bash
cd your-portfolio-repo
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
